# Frame Witness Forensics

Windows software for examining recoverable photos and videos on storage devices and images.

Official website: https://framewitness.pages.dev

## Project preview

Frame Witness focuses on visual examination of recoverable photo and video
content on Windows. Its development workflow brings together a media gallery,
local playback, source offsets, SHA-256 hashes and dates labelled by their source.
Scanner and decoder workers use Windows AppContainer isolation.

The project is seeking practitioner feedback on media-review workflows.
[Explore the product and its limitations](https://framewitness.pages.dev/#product).
The website contains an illustrative demo, not customer evidence or a benchmark.

## Release status

No public software release is available yet. This repository is the designated
distribution channel for future publisher-signed installers and their SHA-256 checksums.
The proprietary application source is kept in a separate private repository.

Email-code account access is available through
[Your licence](https://framewitness.pages.dev/account.html).
Public installer downloads, evaluation registration and purchases are not open.
No payment is required to view the project. Planned prices are not live offers.

Future downloads will include the publisher-signed installer and a SHA-256
checksum. Verify the final artifact before installation; signing does not
guarantee the absence of Windows reputation warnings or software vulnerabilities.

Recovery depends on surviving data. Overwritten or TRIM-erased data cannot be promised.
An onion reference is an indicator, not proof of Tor download provenance.
No police certification or competitor superiority is claimed.
